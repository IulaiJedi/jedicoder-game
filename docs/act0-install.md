# Акт 0 — от скачанного приложения до первой команды

Пять шагов, одинаковых для Windows, macOS и Linux. Тот же текст лежит ещё в
двух местах — в Telegram-боте и на странице сайта; поставить можно по любому.

Шаги идут подряд: закончил один — переходи к следующему.

## По шагам

<a id="node-start"></a>

### Скачай приложение

Игра идёт в приложении Голокрон: внутри него окно с командами, вокруг — акты,
квесты и ранг. Скачай его под свою систему, файл весит около 100 МБ.

Windows: https://github.com/IulaiJedi/golokron-releases/releases/latest/download/golokron-setup.exe

macOS (Mac с чипом Apple: M1, M2 и новее): https://github.com/IulaiJedi/golokron-releases/releases/latest/download/golokron-arm64.dmg

Linux (Ubuntu, Debian): https://github.com/IulaiJedi/golokron-releases/releases/latest/download/golokron-amd64.deb

Файл не скачивается — напиши в канал https://t.me/vibecodejedi: какая система и что ответил браузер.

Дальше:

- [Скачал](#node-open)

<a id="node-open"></a>

### Открой приложение

Windows: запусти скачанный файл. Появится синее окно «Система Windows защитила ваш компьютер» — так Windows встречает любую новую программу. Нажми «Подробнее», потом «Выполнить в любом случае».

macOS: открой файл и перетащи Голокрон в папку «Программы», запусти оттуда. Спросит, открывать ли программу из интернета, — нажми «Открыть». Пишет, что разработчика не удалось проверить? Открой «Системные настройки», раздел «Конфиденциальность и безопасность», нажми «Всё равно открыть».

Linux: дважды щёлкни по файлу и нажми «Установить». Потом найди Голокрон в списке программ и запусти.

Должно открыться окно Голокрона с экраном Подготовки. Не открылось — напиши в канал https://t.me/vibecodejedi, приложи, что написала система.

Дальше:

<a id="node-prepare"></a>

### Приложение поставит остальное

Подготовка — список шагов, и у каждого своя кнопка «Поставить». Нажимай по очереди: команды идут в окне слева, у тебя на глазах. Хочешь набрать их сам — под шагом есть «Сделаю сам — покажи команды».

На Windows первый шаг — Linux внутри Windows. Игра работает в нём, как программа внутри программы. Windows спросит разрешение и попросит перезагрузиться, это нормально.

Шаг «Папка продукта» спросит папку: в ней будет жить то, что ты сделаешь. Заведи новую и пустую, например «moya-igra».

Сделанный шаг закрашивается. Не закрасился — прочитай последние строки в окне слева и нажми «Попробовать снова». Не помогло — напиши в канал https://t.me/vibecodejedi, приложи эти строки.

<a id="node-login"></a>

### Войди в Claude

Последний шаг Подготовки — кнопка «Запустить Claude Code». Claude Code — программа, которой играют: ты пишешь словами, что сделать, она пишет код. Ей нужна платная подписка Claude, Pro или выше: оформи на claude.ai, как подписку на музыку.

Claude Code попросит войти и откроет браузер — подтверди вход там. Браузер не открылся или показал код? Вставь код в окно слева, в строку «Paste code here if prompted».

Вошёл — набери в том же окне первую команду, она ниже. Окно сменится игрой. Не сменилось — закрой Claude Code, снова нажми «Запустить Claude Code» и набери команду первой.

```
/jedicoder:start
```

### Код от бота

Игра живёт на твоём компьютере, а бот игры в Telegram — отдельно. Чтобы бот знал, что это ты, он даёт код: короткую строку вроде номера заказа. В Telegram код придёт следующим сообщением, вместе с командой для него.

Команду набери в окне слева, а не в разговоре с игрой. В Голокроне вторая вкладка открывается кнопкой «+».

Код — не пропуск: без него игра проходится целиком, просто бот не увидит твой путь. Не пришёл или не принялся — напиши в канал https://t.me/vibecodejedi.

Дальше говорит игра. Удачи.
