# Акт 5 · Выход в свет

> *«Продукт, которого никто не видел, не существует»*

## Перед началом

1. Загрузи контракт и следуй ему: `python3 "$(cat ~/.jedicoder/plugin_root)/lib/jedicoder/cli.py" contract`
2. Войди в акт: `python3 "$(cat ~/.jedicoder/plugin_root)/lib/jedicoder/cli.py" enter 5`
3. CLI напечатал текст катсцены — прочитай его падавану дословно, не
   пересказывая. Единственный источник: `content/ru/acts/act5-vyhod-v-svet.md`.
   Своей катсцены у скилла нет и быть не должно.
4. Скажи падавану, что он получил артефакт `deploy` — выкладка по его пути.
5. Если игра напечатала вопрос про Голокрон — задай его падавану своими
   словами и запиши ответ **этой командой** (сама игра терминал не читает):

   ```bash
   python3 "$(cat ~/.jedicoder/plugin_root)/lib/jedicoder/cli.py" book yes
   # или ... book no
   ```

6. На схеме пайплайна из Акта 2 он вот здесь: финал — код уезжает на
   сервер и обретает адрес.

## Квесты по порядку

| Квест | Что делает падаван |
|---|---|
| `01-deploy` | деплоит по пути из Акта 4 (артефакт `/deploy`, перед выкаткой — Ситх-ревьюер), называет адрес: `project url <https://…>`; на vps дополнительно `project service <юнит>` |
| `02-domain` | покупает домен, заводит A-запись (или подключает домен в панели), обновляет `project url` |
| `03-ssl` | выпускает сертификат (платформа — кнопкой, vps — certbot) |
| `04-health` | заводит в приложении маршрут `/health`; подключить Sentry — настоятельный шаг здесь же, но игра его не проверяет |
| `05-goal` | применяет `/goal` к живому продукту — с лимитом попыток и критерием |
| `06c-use` | (Ремесленник) три дня пользуется своим продуктом |
| `06f-publish` | (Основатель) публикует в канале из Акта 1: `project post <ссылка>` |

Состав зависит от трека — как в Акте 1. Проверки: `check 5 <квест>`,
подтверждения: `ack 5 <квест>`.

## Как вести каждый квест

1. **Возражение Магистра** — правило 7 контракта, загруженного шагом 1.
2. Помоги сделать. Термин впервые — поясни одной фразой в скобках.
3. Прогони проверку, объясни только непройденное, помоги исправить.
4. Третья попытка — CLI напечатает протокол выхода из круга. Выполни его.

## Квест 01 — Ситх перед выкаткой

Перед первым деплоем прогони Ситх-ревьюера (агент `sith-reviewer`) по
проекту: его задача — доказать, что это сломается. Найденное почини до
выкатки. Ситх ничего не засчитывает — исход квеста решает только `check`.

## Квест 05 — /goal

Сценарий: падаван формулирует цель по форме `/goal <цель>, стоп после
<N> попыток` — например «подними https://домен/health до 200, стоп после
5 попыток». Внутри цикла используй его собственный скилл верификации из
Акта 3. Когда цикл отработал и остановился по правилу — подтверди:
`ack 5 05-goal`.

## Квест 06c — подтверждение Ремесленника

Три дня реального пользования — критерий из Акта 1. Спрашивай по дням,
что он менял по итогам собственного использования. Когда три дня прожиты
по-настоящему — `ack 5 06c-use`. Подтверждение авансом — обман себя.

## После акта

Акт закрывается сам на последнем квесте — падаван становится **Мастером**.
Сразу покажи карточку: `python3 "$(cat ~/.jedicoder/plugin_root)/lib/jedicoder/cli.py" finale`
— и предложи поделиться ею. Дальше — клуб и следующий продукт; игра на
этом заканчивается, путь — нет.
