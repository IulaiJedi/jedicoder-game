# Акт 3 · Первая кровь

> *«Ты сломаешь. Это не провал — это как встают на два колеса»*

## Перед началом

1. Загрузи контракт и следуй ему: `python3 "$(cat ~/.jedicoder/plugin_root)/lib/jedicoder/cli.py" contract`
2. Войди в акт: `python3 "$(cat ~/.jedicoder/plugin_root)/lib/jedicoder/cli.py" enter 3`
3. CLI напечатал текст катсцены — прочитай его падавану дословно, не
   пересказывая. Единственный источник: `content/ru/acts/act3-pervaya-krov.md`.
   Своей катсцены у скилла нет и быть не должно.
4. Скажи падавану, что он получил артефакт `investigate` — систематический дебаг.
5. Если игра напечатала вопрос про Голокрон — задай его падавану своими
   словами и запиши ответ **этой командой** (сама игра терминал не читает):

   ```bash
   python3 "$(cat ~/.jedicoder/plugin_root)/lib/jedicoder/cli.py" book yes
   # или ... book no
   ```

6. Спроси, на каком порту поднимается его проект, и запиши:
   `python3 "$(cat ~/.jedicoder/plugin_root)/lib/jedicoder/cli.py" project port <номер>`

## Квесты по порядку

| Квест | Что делает падаван |
|---|---|
| `01-launch` | поднимает проект локально, называет порт |
| `02-feature` | делает первую фичу, коммитит шаги по ходу |
| `03-break` | ломает проект НАРОЧНО и коммитит слом с пометкой «слом:» |
| `04-fix` | читает трейсбек, скармливает ошибку целиком, чинит, коммитит |
| `05-decisions` | заводит DECISIONS.md — журнал решений |
| `06-context7` | подключает MCP context7 — свежие доки вместо устаревшей памяти |
| `07-git-safety` | git log, git diff, откат файла, git revert |
| `08-skill` | записывает свою ручную проверку скиллом в .claude/skills |
| `09-loop-protocol` | применяет протокол «ИИ ходит по кругу» на живой проблеме |
| `10-boss` | босс «Забитый контекст»: перенос знания в файлы и новый чат |

Порядок жёсткий: `04` чинит то, что сломал `03`; босс опирается на журнал
из `05` и навык из `08`.

## Как вести каждый квест

1. **Возражение Магистра** — правило 7 контракта, загруженного шагом 1.
2. Помоги сделать. Термин впервые — поясни одной фразой в скобках.
3. Прогони проверку:
   `python3 "$(cat ~/.jedicoder/plugin_root)/lib/jedicoder/cli.py" check 3 <квест>`
4. Не сошлось — объясни **только** непройденные пункты и помоги исправить.
5. Третья попытка — CLI напечатает протокол выхода из круга. Выполни его.

## Квест 01 — врезка про контекстное окно

Играется в этом квесте, а не перед боссом: разговор становится длинным ровно
здесь, когда проект первый раз поднимается. Скажи своими словами, но эти
мысли должны прозвучать:

> Разговор с ИИ не бесконечен. У него есть окно — сколько текста модель
> видит разом. Всё, что не влезло, для неё не существует: как будто этого
> и не говорили.
>
> Отсюда «ИИ поглупел к вечеру». Он не устал — старое вытолкнуто из окна.
> Когда окно заполняется, Claude Code сам сжимает разговор в пересказ:
> сессия не обрывается, но детали теряются.
>
> Сколько занято прямо сейчас, покажет `/context`. Это не цифра на память,
> а привычка посмотреть, прежде чем удивляться ответу.

Чисел не называй: ни размера окна, ни лимитов, ни версии. Падаван учится
проверять командой, а не запоминать цифру, которая устареет.

## Квест 02 — врезка про чистый чат и расход

Играется здесь, потому что первая фича — это первый по-настоящему длинный
разговор. Скажи своими словами, но эти мысли должны прозвучать:

> Сжатие переживает не всё. Корневой `CLAUDE.md` перечитывается с диска
> после сжатия — вот единственная причина, по которой знание переносят в
> файлы, а не пересказывают заново. Вложенные правила и то, что нигде не
> записано, теряются.
>
> Поэтому порядок такой: сначала важное в файл, и только потом `/clear` —
> чистый чат с пустого места. Освободить место, не начиная заново, — это
> `/compact`, и он не бесплатен: чтобы сжать разговор, его надо прочитать
> целиком. `/clear` не стоит ничего.
>
> И то, что объясняет главную загадку новичка «я почти ничего не делал, а
> лимит кончился»: на длинной сессии каждый запрос тащит с собой всю
> историю. Однострочный вопрос в чате, открытом с утра, оплачивается как
> весь этот день.
>
> `/usage` покажет расход и когда лимиты сбросятся. Долларовая цифра там —
> локальная оценка, и вместе с чистым чатом счётчики обнуляются.

Чисел не называй: ни размера окна, ни лимитов, ни версии. Падаван учится
проверять командой, а не запоминать цифру, которая устареет.

## Квест 03 — важные детали

Слом — намеренный и безопасный, потому что перед ним коммит. Предложи
падавану самому выбрать, что сломать (убрать кавычку, переименовать
переменную). Сообщение коммита обязано начинаться со «слом:» — по этой
метке игра отличит слом от починки. Когда проект упал — НЕ чини сразу:
сначала прочитайте трейсбек вместе, с последней строки вверх.

## Квест 05 — важная деталь

Формат записи: `## ГГГГ-ММ-ДД — что решили` и абзац «почему, что отвергли».
Проверка требует записей минимум в два разных дня — квест закроется не
сегодня, и это нормально: журнал ведут по ходу, а не задним числом.
Возвращайся к нему после каждого настоящего решения.

## Квест 09 — подтверждение

У квеста нет автопроверки. Когда падаван реально применил протокол
(откат на рабочий коммит, чистый чат командой `/clear`, ошибка целиком,
«объясни причину, не чини») — подтверди:
`python3 "$(cat ~/.jedicoder/plugin_root)/lib/jedicoder/cli.py" ack 3 09-loop-protocol`

## Босс — Забитый контекст

Здесь ничего не вводится — здесь применяется. Про окно падаван услышал в
квесте `01`, про чистый чат и расход — в квесте `02`. Ни одного нового слова
у босса нет, и добавлять его сюда не надо.

Победа: всё важное о проекте перенесено в CLAUDE.md, начат новый чат, работа
продолжена без потерь — проверка сверяет CLAUDE.md по хэшу со времён Акта 2.

Вопрос, с которого начинается бой, — не «что такое окно», а «что из
сегодняшнего разговора ты потеряешь, если дать `/clear` прямо сейчас».
Ответ на него и есть список того, что надо дописать в файл до боя.
