title: .env не уезжает в git

Однажды человек закоммитил `.env` с ключами и запушил. Через месяц на его
сервере молотил чужой майнер Monero — счёт за электричество пришёл раньше,
чем догадка.

**Почему:** файл, попавший в историю git, остаётся там навсегда — даже
если ты удалишь его следующим коммитом. У репозитория на GitHub история
видна всем, у кого есть доступ, а у публичного — всем вообще. Боты
сканируют новые коммиты и находят ключи за минуты.

**Что делать вместо:** держи `.env` в `.gitignore` с первого дня. Если он
уже в индексе — `git rm --cached .env` и коммит. Если он уже в истории —
сначала отзови и перевыпусти сам ключ, и только потом чисти историю:
чистка без ротации бесполезна.
