rule: env-never-in-git
title: .env не уезжает в git
act: 2
severity: high
dark_side: true
xp: 10
---
Однажды человек закоммитил `.env` с ключами и отправил на GitHub. Через
месяц его сервер добывал криптовалюту для чужого человека — счёт пришёл
раньше догадки.

**Почему:** файл, попавший в историю git, остаётся там навсегда, даже
если удалить его следующим коммитом. На GitHub историю видят все, у кого
есть доступ, а у публичного — все вообще. Боты сканируют новые коммиты и
находят ключи за минуты.

**Что делать вместо:** держи `.env` в `.gitignore` с первого дня. Уже в
индексе — `git rm --cached .env` и коммит. Уже в истории — сначала отзови
и перевыпусти сам ключ, потом чисти историю. Чистка без ротации
бесполезна.
