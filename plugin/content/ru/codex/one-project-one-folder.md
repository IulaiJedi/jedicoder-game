Не складывай два продукта в одну папку. Каждому — своя, и в ней больше
ничего: ни соседней недоделки, ни скачанного курса.

**Почему:** по этой папке считается всё: проверки квестов, сохранения,
штрафы за утёкшие ключи. Смешаешь два проекта — их истории срастутся, и
разделить их уже нельзя. Проверки начнут читать чужие файлы и врать.
Выглядит это как поломка игры, и вечер уйдёт на поиск не там.

**Что делать вместо:** новый продукт — новая папка, всегда. Проверка
простая: удалишь папку целиком — исчезнет ровно один продукт. Исчезает
больше — папка выбрана неверно, и игре надо назвать не её.
