title: Один продукт — одна папка

Не складывай два продукта в одну папку. Каждому — своя, и в ней больше
ничего: ни соседней недоделки, ни скачанного курса.

**Почему:** по этой папке считается всё. Игра гоняет в ней проверки квестов,
git ведёт в ней историю, хук Тёмной стороны только внутри неё судит про
утёкшие ключи. Смешаешь два проекта — история срастётся так, что разделить
её уже нельзя, а проверки начнут читать чужие файлы и врать. Выглядеть это
будет как поломка игры, и ты потратишь вечер, ища причину не там.

**Что делать вместо:** новый продукт — новая папка, всегда. Проверка простая:
если удалить папку целиком, должен исчезнуть ровно один продукт. Исчезает
больше — папка выбрана неверно, и назвать игре надо не её.
