Работать на сервере под root — как ходить по дому с включённой
бензопилой. Один раз обойдётся, привычка — нет.

**Почему:** под root любая команда исполняется без вопросов, включая
ошибочные и чужие. Взломанный root — это не часть сервера, это весь
сервер: ключи, база, деньги, домен.

**Что делать вместо:** заведи обычного пользователя, дай ему ключ и ходи
под ним. Права поднимай на одну команду через `sudo`. Этому учит квест
`03v-user` Акта 4.
