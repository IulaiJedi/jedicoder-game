Игра запускается не где попало, а в папке твоего продукта. Папки этой пока
нет, и сама она не появится — заведи её двумя строками:

```
mkdir -p ~/projects/moya-igra
cd ~/projects/moya-igra
```

Первая создаёт папку, вторая переводит тебя внутрь. Имя `moya-igra` замени
на своё — латиницей и без пробелов; кириллица и пробелы в путях ломают
половину инструментов, а ты этого не заслужил.

Одно правило про эту папку важнее, чем звучит: один продукт — одна папка, и
больше в ней не лежит ничего. Игра гоняет проверки именно там, git ведёт там
историю. Свалишь два проекта в одну — история перемешается, а проверки
начнут читать чужие файлы и врать.
