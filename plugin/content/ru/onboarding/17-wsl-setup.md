Нажми правой кнопкой по кнопке Пуск и выбери в меню Windows PowerShell
(администратор). Набери там:

```
wsl --install -d Ubuntu
```

Имя системы названо нарочно. Голая форма, без него, ставит Linux только на
машине, где WSL нет вовсе; если он уже стоит хоть как-нибудь, она печатает
свою справку и не делает ничего.

Перезагрузи компьютер. После перезагрузки откроется окно Ubuntu и попросит
придумать имя и пароль — это отдельный пользователь внутри Linux. Всё
дальнейшее ты делаешь в этом окне.

Одна грабля заранее: позже, на входе в аккаунт, браузер из WSL может не
открыться сам, а вместо него появится код. Это штатное поведение.
