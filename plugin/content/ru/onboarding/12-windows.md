Claude Code на Windows работает. Anthropic поддерживает и обычный Windows, и
WSL — если где-то написано обратное, это неправда.

А вот проверки этой игры написаны для bash, языка команд Linux. Обычный
Windows их не выполнит. Поэтому нужен WSL — настоящий Linux внутри твоего
Windows. Это самый длинный шаг всей установки.

Набирать его руками не обязательно. У игры есть своё окно — Голокрон, — а
внутри него Подготовка: она ставит и Linux внутри Windows, и Claude Code, и
саму игру, у тебя на глазах, в настоящем терминале. Прав администратора она
всё равно спросит, и перезагрузка всё равно будет — но команды набирает она,
и что ответила машина, разбирает тоже она.

А когда поставит, останется окном игры: терминал внутри, вокруг — карта
актов, квесты и ранг.

Что выбираешь?
