Спокойно. «Нет такой команды» здесь значит одно из двух: игра не поставилась
или Claude Code про неё ещё не знает. Что именно — покажет одна строка,
набранная в терминале, а не внутри Claude Code; в Голокроне терминал
открывается второй вкладкой по кнопке «+»:

```
claude plugin list
```

Он напечатает список того, что у него стоит. Ищи в нём строку
`jedicoder@jedicoder`, а рядом с ней слово `enabled`.

Если строка есть — игра на месте, и дело в старом окне: оно смотрело список
до того, как игра появилась. Закрой Claude Code целиком — хоть терминальный,
хоть приложение, хоть Голокрон — и запусти заново.

Если строки нет — установка не прошла. Последняя кнопка вернёт к двум
строкам установки: выполни их ещё раз, по одной, и прочитай, что ответила
каждая.
