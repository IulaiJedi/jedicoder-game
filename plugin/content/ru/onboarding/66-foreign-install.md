Значит Claude Code стоит у тебя не тем способом, которым мы его ставим. Так
бывает: в интернете до сих пор советуют ставить его пакетным менеджером
узла, а он ставит то же самое в другое место.

Откуда именно — покажут три строки:

```
ls -la ~/.local/bin/claude
ls -la ~/.claude/local/
npm -g ls @anthropic-ai/claude-code
```

«No such file or directory» в первых двух — не ошибка, а ответ «здесь пусто».

Самый частый случай: npm с нестандартным местом установки. Оно не добавляет
свой каталог в список путей — это делает человек руками. Отсюда и «команды
нет» при полностью успешной установке.

Официальный установщик такого не создаёт вовсе.
