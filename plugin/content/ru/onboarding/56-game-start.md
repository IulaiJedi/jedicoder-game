Запусти Claude Code прямо здесь, в этой папке:

```
claude
```

Если он у тебя уже открыт — закрой его совсем и запусти заново. Заново
именно программу, а не разговор в том же окне: какие команды у него есть,
Claude Code смотрит один раз, при запуске. Игру, поставленную позже, старое
окно не увидит, сколько с ним ни говори.

Первой командой набери:

```
/jedicoder:start
```

Именно первой: правила игры подхватываются на старте, и разговор, начатый
раньше, пойдёт мимо них — игра будет вести себя странно, а ты не поймёшь
почему.
