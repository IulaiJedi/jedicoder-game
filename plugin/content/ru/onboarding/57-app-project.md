Тогда папку руками заводить не надо: приложение спросит её само.

Открой приложение, перейди на вкладку Code и начни новую сессию. Оно спросит
папку проекта — выбери пустую папку под свой продукт или заведи новую прямо
там. Правило про неё одно, и оно важнее, чем звучит: один продукт — одна
папка, и больше в ней не лежит ничего. Свалишь два проекта в одну — проверки
игры начнут читать чужие файлы и врать.

Если приложение было открыто, пока ты ставил игру, закрой его целиком и
открой заново: какие команды у него есть, оно смотрит один раз, при запуске.

Первой командой в новой сессии набери:

```
/jedicoder:start
```
