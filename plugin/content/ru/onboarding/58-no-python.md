Поправимо, и быстро.

В WSL и на Ubuntu:

```
sudo apt install -y python3
```

Пароль спросят — это тот же пароль, которым ты входишь в систему.

На macOS python3 приезжает вместе с инструментами разработчика:

```
xcode-select --install
```

Откроется окно с кнопкой — согласись и дождись конца.

Потом проверь тем же `python3 --version`. Ответ, начинающийся с «Python 3», —
готово, возвращайся.

Если после установки команда всё ещё не находится, закрой терминал и открой
заново: список команд читается при его запуске.
