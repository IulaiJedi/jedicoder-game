Последнее дело на сегодня. Две строки — в том же терминале, не внутри Claude
Code:

```
claude plugin marketplace add IulaiJedi/jedicoder-game
claude plugin install jedicoder@jedicoder
```

Первая говорит Claude Code, где игру брать. Вторая её ставит.

Теперь запусти Claude Code в папке проекта, над которым будешь работать, и
набери:

```
/jedicoder:start
```

**Именно первой командой в свежей сессии.** Правила игры подхватываются при
старте сессии — разговор, начатый раньше, пойдёт мимо них, и игра будет вести
себя странно.

Ключ привязки вводится уже внутри, строкой из этого чата. Забудешь — не
страшно: путь просто останется на твоей машине.

Дальше говорит игра. Удачи.
