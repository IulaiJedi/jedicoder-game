Теперь сама игра. Две строки — в том же терминале, не внутри Claude Code.

Выполняй их по одной. Сначала эту:

```
claude plugin marketplace add IulaiJedi/jedicoder-game
```

Она говорит Claude Code, где игру брать. Дождись, пока снова появится
приглашение ввода, — и только тогда вторую:

```
claude plugin install jedicoder@jedicoder
```

Эта её ставит.

Почему по одной, а не обе разом. Вставленные вместе, они уедут в терминал
одним куском: споткнётся первая — вторая всё равно побежит, и в ответе будет
не видно, чья это ругань. Два раза нажать Enter дешевле, чем потом гадать.

Игра поставлена. Дальше скажи, чем ты пользуешься: терминалом, где ты сейчас
и находишься, или приложением Claude — тем, что с окном и кнопками. Ставится
игра одинаково, а вот запускается по-разному.
