Номер версии напечатан — значит поставилось. Осталось войти в аккаунт: без
этого Claude Code запустится, но работать не станет.

Перейди в любую папку с твоим проектом и набери:

```
claude
```

Он предложит войти. Выбирай вход по оплаченному аккаунту и подтверди в
браузере.

И обещанная грабля: если ты в WSL, браузер может не открыться сам. Вместо
перехода появится код — скопируй его из браузера на Windows и вставь обратно
в окно WSL. Это штатное поведение WSL, а не поломка установки.
