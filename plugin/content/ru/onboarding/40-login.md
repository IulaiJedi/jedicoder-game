Последний шаг Подготовки — кнопка «Запустить Claude Code». Claude Code — программа, которой играют: ты пишешь словами, что сделать, она пишет код. Ей нужна платная подписка Claude, Pro или выше. Оформляется на claude.ai, российские карты там не принимают.

Claude Code попросит войти и откроет браузер — подтверди вход там. Браузер не открылся или показал код? Вставь код в окно слева, в строку «Paste code here if prompted».

Кнопка открывает Claude Code в режиме без вопросов. В нём он правит файлы и запускает команды, не спрашивая. На новом компьютере он два раза спросит по-английски: про папку проекта и про режим. Оба раза нажми стрелку вниз и Enter. Просто Enter выбирает «No, exit» и закрывает его. Приложение подскажет справа, что нажать.

Дальше игра начнётся сама, и окно сменится игрой. Не началась — набери в окне слева команду, она ниже.
