Последний шаг Подготовки — кнопка «Запустить Claude Code». Claude Code — программа, которой играют: ты пишешь словами, что сделать, она пишет код. Ей нужна платная подписка Claude, Pro или выше. Оформляется на claude.ai, российские карты там не принимают.

Claude Code попросит войти и откроет браузер — подтверди вход там. Браузер не открылся или показал код? Вставь код в окно слева, в строку «Paste code here if prompted».

Кнопка открывает Claude Code в режиме без вопросов. В нём он правит файлы и запускает команды, не спрашивая. При первом запуске он по-английски спросит согласия на этот режим. Ещё он спросит, доверяешь ли ты папке проекта. Оба раза выбери согласие.

Вошёл — набери в том же окне первую команду, она ниже. Окно сменится игрой. Не сменилось — закрой Claude Code, снова нажми «Запустить Claude Code» и набери команду первой.
