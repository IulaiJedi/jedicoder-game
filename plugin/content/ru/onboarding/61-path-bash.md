Так отвечает bash — оболочка по умолчанию в Linux и в WSL. Проверим главное
подозрение: система не знает, где лежит поставленное.

Выполни:

```
echo $PATH | tr ':' '\n' | grep -Fx "$HOME/.local/bin"
```

Эта строка ищет каталог установки в списке мест, где система ищет программы.
Ответ бывает ровно двух видов: либо она напечатает путь, либо не напечатает
ничего.

Пустой ответ здесь — не ошибка, а находка: значит каталог в список не попал,
и мы знаем, что чинить.
