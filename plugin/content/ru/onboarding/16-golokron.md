Скачать: https://jedicoder.store/golokron — там установщики для Windows и
Linux. Под macOS Голокрона пока нет.

На Windows при запуске установщика появится синее окно «Система Windows
защитила ваш компьютер». Это не поломка и не вирус: программа не подписана
сертификатом, а Windows перестаёт предупреждать только тогда, когда у
программы накопится репутация — то есть её скачают многие и ни у кого ничего
не сломается. Нажми «Подробнее», а потом «Выполнить в любом случае».

Поставил — открывай. Дальше говорит Подготовка: она пройдёт с тобой всё, что
осталось, и доведёт до первого запуска игры. Папку продукта заводить заранее
не надо — её спросят.

Одного она за тебя не сделает: Claude Code открывается только оплаченным
планом Anthropic. Плана нет — заведи его на сайте Anthropic, иначе упрёшься в
это на входе в аккаунт.
