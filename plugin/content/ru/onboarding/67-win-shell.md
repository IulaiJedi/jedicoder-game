Так отвечают оболочки самого Windows — значит команду ты набираешь не в том
окне. Различить их можно по началу строки ввода: в PowerShell она начинается
с букв PS и дальше диск, в командной строке — сразу с диска.

Проверки этой игры написаны для bash, и ни одна из этих двух оболочек их не
выполнит. Нам нужно окно WSL.

Посмотри в PowerShell, что WSL на месте:

```
wsl --list --verbose
```

Есть дистрибутив в списке — набери wsl и нажми Enter: ты внутри Linux, и все
команды теперь набираешь там.

Список пуст или команда не найдена — WSL ещё не стоит.
