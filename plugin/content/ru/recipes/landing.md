## Стек и почему такой

Чистые HTML, CSS и немного JS — без сборщиков и фреймворков: ИИ их
генерирует почти без ошибок, а статика хостится бесплатно. Фреймворк здесь —
плата за то, чего посетитель не увидит.

## Пять типичных грабель именно здесь

1. **Три кнопки с разными целями.** Не нажмут ни одну: одна страница — одно
   действие.
2. **Форма, которая никуда не шлёт.** Без обработчика она молча съедает
   заявки. Отправь заявку сам.
3. **Картинки по десять мегабайт.** Страница грузится пять секунд —
   посетитель ушёл. Сжимай перед выкладкой.
4. **Вёрстка только под твой экран.** Больше половины трафика — телефоны:
   открой со своего.
5. **Аналитики нет.** Без счётчика не узнаешь, приходил ли кто-нибудь.

## Что проверить в конце

- страница открывается по публичной ссылке с телефона
- целевое действие срабатывает: заявка доходит
- счётчик аналитики зафиксировал твой визит
