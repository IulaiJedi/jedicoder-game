**GitHub** — сайт, где лежит копия твоего проекта со всеми сохранениями.

**Зачем нужно:** пока проект только на компьютере, он живёт в одном месте.
Сломается компьютер — пропадёт всё. С копией на GitHub ничего не потеряно:
на новом компьютере подключаешь GitHub и скачиваешь проект.

**Git и GitHub — разное:** git — программа на твоём компьютере, она хранит
сохранения. GitHub — сайт, где лежит их копия. Регистрация бесплатная,
ставить ничего не надо.

**Как выглядит:** страница вида `github.com/<имя>/<папка>` — там файлы
проекта и все сохранения. Отправляет их туда Claude по твоим словам: «Сделай
коммит и отправь на GitHub».

**Ещё там:** чужие программы и скиллы, которые люди выкладывают для всех.

**Проверь, что понял:** чем git отличается от GitHub?
