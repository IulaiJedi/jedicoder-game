**Репозиторий** — хранилище кода проекта: та же папка, только на GitHub.

**Зачем нужно:** в репозитории лежат файлы проекта и все его сохранения. Из
него проект скачивают на любой компьютер.

**Открытый и приватный:** открытый репозиторий видят все — так выкладывают
программы для всех. Приватный, то есть закрытый, видишь только ты. Твой
проект — в приватном.

**Как выглядит:** адрес вида `git@github.com:<имя>/<папка>.git`. На сайте
рядом с названием стоит слово `Private` — «закрытый».

**Проверь, что понял:** кто увидит твой приватный репозиторий?
