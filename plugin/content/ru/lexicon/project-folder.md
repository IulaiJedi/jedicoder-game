**Папка проекта** — одна папка на одну затею: в ней код, заметки и
настройки Claude Code.

**Зачем нужно:** Claude Code видит и правит то, что лежит в открытой
папке. Одна затея в папке — он не тронет чужого и не перепутает файлы.

**Как выглядит:** новая затея — новая папка с нуля. Внутри со временем
появятся файл `CLAUDE.md` с правилами проекта и папка `.claude` с
настройками.

**Проверь, что понял:** в какой папке открыт Claude Code прямо сейчас?
