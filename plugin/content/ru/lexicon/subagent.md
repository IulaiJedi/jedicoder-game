**Субагент** — отдельный ИИ с собственным чистым контекстным окном, которому
главный агент поручает кусок работы и получает назад только результат.

**Зачем нужно:** большая задача съедает окно быстро. Поиск по всему проекту,
ревью, проверка — работа для субагента: он перелопатит тысячи строк, а в
твой чат вернётся три предложения выводов.

**Проверь, что понял:** почему результат субагента дешевле для окна, чем
та же работа в основном чате?
