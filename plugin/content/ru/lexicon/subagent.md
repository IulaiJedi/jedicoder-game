**Субагент** — отдельный ИИ с чистой памятью: получает кусок работы,
возвращает только результат.

**Зачем нужно:** большая задача съедает окно быстро. Поиск по проекту,
ревью, проверка — работа для субагента. Твой чат при этом остаётся чистым.

**Проверь, что понял:** почему результат субагента дешевле для окна, чем
та же работа в чате?
