**API** — способ, которым одна программа просит что-то у другой и получает
ответ.

**Зачем нужно:** почти всё, что кажется магией, — чужой API: карта, оплата,
распознавание речи. Своё писать не надо, надо уметь попросить.

**Как выглядит:** отправил на `/api/transcribe` файл — получил текст с
таймкодами. Что внутри — не твоя забота, важен только договор о запросе и
ответе.

**Проверь, что понял:** какой чужой API нужен твоей первой версии и что
именно ты у него попросишь?
