**CI/CD** — автоматика вокруг репозитория: на каждый пуш прогнать
проверки (CI) и, если зелено, задеплоить (CD). Пуш в main — и через
минуты код в проде, без рук.

**Зачем нужно:** ручной деплой забывается, ломается и откладывается.
Когда выкладка — побочный эффект пуша, она перестаёт быть событием.
Платформы дают CD из коробки: подключил репо — получил пайплайн.

**Проверь, что понял:** что должно случиться после твоего следующего
пуша в main — по шагам?
