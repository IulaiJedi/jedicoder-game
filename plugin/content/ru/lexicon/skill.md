**Скилл** — файл с инструкциями, который даёт Claude новое умение.

**Зачем нужно:** Claude многое умеет сразу, без добавок. Скилл учит его
делать одно дело хорошо: оформить страницу, вести разработку по шагам. Свой
можно сделать за минуту.

**Где брать:** почти все скиллы лежат на GitHub — сайте, где люди бесплатно
выкладывают свои программы. Ищут обычным поиском по своей задаче. Например:
«claude design skill» — скилл для дизайна. Ставят по ссылке словами: «Вот
ссылка на скилл. Проверь; если полезный — скажи чем и установи».

**Сначала «проверь»:** скилл — чужой текст, и Claude сделает то, что в нём
написано. В режиме без вопросов Claude доступен весь твой компьютер. В
открытом доступе бывает вредный код. Поэтому каждый скилл перед установкой
Claude сначала читает и ищет в нём вредные скрипты.

**Под задачу:** много скиллов — не значит лучше. Скиллы разных авторов
спорят между собой, и Claude работает хуже. Ставь скилл под задачу, в папку
проекта. Для всех проектов — только то, что нужно везде.

**Как выглядит:** папка с файлом `SKILL.md`. Лежит в папке проекта —
работает только в этом проекте. Лежит в домашней папке — работает во всех
проектах. Список скиллов показывает команда `/skills`.

**Скилл или строка в CLAUDE.md:** строка в `CLAUDE.md` — правило на всегда.
Скилл — умение по случаю: Claude берёт его, когда оно к месту.

**Проверь, что понял:** почему перед установкой скилла сначала говорят
«проверь»?
