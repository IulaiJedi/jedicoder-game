**API-ключ** — пароль, по которому сервис узнаёт твою программу.

**Зачем нужно:** по ключу сервис знает, чья программа к нему пришла, и
считает её лимиты. Кто знает ключ, тот работает от твоего имени и за твой
счёт.

**Где взять:** в личном кабинете сервиса — в настройках или в разделе для
разработчиков. Нужен ли ключ вообще, Claude скажет по документации: многим
сервисам он не нужен.

**Где хранить:** только в файле `.env` в папке проекта. Claude ключ дать
можно: «Вот ключ, положи его в `.env`». Посторонним его не показывай. В код,
в сохранения и на GitHub он не попадает.

**Если ключ утёк:** выпусти в кабинете сервиса новый ключ, старый удали.
Новый — в `.env`. Переписывать сохранения не нужно: удалённый ключ уже не
работает.

**Проверь, что понял:** где живёт ключ сервиса и почему не в коде?
