**MCP** — способ подключить сервис к нейросети: как API, только для нейросетей.

**Зачем нужно:** API сделан для программ, MCP — для нейросетей вроде
Claude. Через MCP Claude сам работает с сервисом прямо в разговоре.

**Как узнать:** первый вопрос о любом сервисе — есть ли у него API или MCP.
Ответ лежит в документации для разработчиков. Разбирается в ней Claude, от
тебя — ссылка.

**Проверь, что понял:** какой первый вопрос задают о сервисе, который хотят
подключить?
