**MCP** (Model Context Protocol) — способ дать ИИ дополнительные руки:
подключаемые серверы с инструментами — свежие доки, браузер, база данных.

**Зачем нужно:** память ИИ заморожена в прошлом, а библиотеки обновляются.
context7 по MCP приносит документацию сегодняшнего дня — и ИИ перестаёт
предлагать методы, которых больше нет.

**Проверь, что понял:** когда ИИ советует несуществующий метод библиотеки —
что подключить?
