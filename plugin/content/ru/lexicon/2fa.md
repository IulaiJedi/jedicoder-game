**2FA** — второй ключ при входе: кроме пароля просят код из приложения на
телефоне.

**Зачем нужно:** GitHub и панель хостинга — это весь твой продукт: код,
ключи, домен. Пароль утекает буднично: подсмотрели, угадали, украли с
чужого сайта. С 2FA утечка пароля — неприятность, а не катастрофа.

**Проверь, что понял:** на каких двух аккаунтах 2FA нужен твоему проекту
прямо сейчас?
