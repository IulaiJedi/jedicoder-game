**sudo** — «выполни эту команду с правами главного пользователя» — на одну
команду, не навсегда.

**Зачем нужно:** это ремень безопасности. Ошибка с sudo стоит одной
команды, ошибка под root — всей системы. Если каждая вторая команда
требует sudo — что-то не так с настройкой.

**Проверь, что понял:** почему `sudo rm -rf` опаснее, чем `rm -rf`?
