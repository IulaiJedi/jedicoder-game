**sudo** — «выполни эту команду с правами суперпользователя». Обычный
пользователь живёт с обычными правами и поднимает их на одну команду,
когда это правда нужно.

**Зачем нужно:** это ремень безопасности. Ошибка с sudo стоит одной
команды, ошибка под root — всей системы. Если каждая вторая команда
требует sudo — что-то не так с настройкой, а не с командами.

**Проверь, что понял:** почему `sudo rm -rf` опаснее, чем `rm -rf`?
