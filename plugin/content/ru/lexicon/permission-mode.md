**Режим разрешений** — настройка: что Claude делает сам, а о чём сначала
спрашивает тебя.

**Зачем нужно:** игра рассчитана на режим без вопросов. В нём Claude
правит файлы и запускает команды, не спрашивая. Это быстро. Но Claude
может ошибиться, поэтому так работают только в папке проекта.
Другие режимы строже. Обычный спрашивает перед правкой и перед командой.
Режим плана читает и предлагает, но файлов не меняет.

**Как выглядит:** режим называет игра. В окне он написан под строкой
ввода, по-английски: в режиме без вопросов там стоит
`bypass permissions on`. Переключает режимы `Shift+Tab`. Режим без
вопросов есть в этом круге, только если Claude Code с ним запущен.

**Что остаётся и в этом режиме:** стереть корень диска или домашнюю папку
Claude Code всё равно переспросит. Защита игры тоже работает: команду,
которая стирает файлы вне папки проекта, она остановит.

**Проверь, что понял:** что Claude делает без спроса в режиме без вопросов?
