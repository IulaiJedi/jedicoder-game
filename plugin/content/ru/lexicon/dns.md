**DNS** — адресная книга интернета: превращает имя домена в адрес сервера.

**Зачем нужно:** без DNS продукт открывается только по адресу из цифр: он
не запоминается и не годится для сертификата. Записи правишь там, где
купил домен. Меняются они не сразу — до нескольких часов.

**Проверь, что понял:** почему после смены A-записи сайт открывается не у
всех сразу?
