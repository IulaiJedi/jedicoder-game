**DNS** — телефонная книга интернета: превращает имя домена в IP-адрес
сервера. Когда кто-то открывает твой сайт, первым делом спрашивают DNS.

**Зачем нужно:** без DNS твой продукт доступен только по IP — который
меняется, не запоминается и не годится для сертификата. Записи DNS
правишь у регистратора домена, и меняются они не мгновенно — до
нескольких часов.

**Проверь, что понял:** почему после смены A-записи сайт открывается не
у всех сразу?
