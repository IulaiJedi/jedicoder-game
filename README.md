# Jedicoder

Игра, которая учит работать с Claude Code с нуля. Claude Code — программа,
которая пишет код по твоим словам. Учишься ты сразу на своей затее: учебного
примера в игре нет.

Игра для того, кто впервые открыл Claude Code. Опыт программирования не нужен.

Главное правило игры: **исход квеста решает exit-код bash-скрипта, а не мнение
модели.** Скрипт смотрит на файлы в папке твоего проекта и отвечает «да» или
«нет». Засчитать квест по доброте игра не может.

Не всё видно в папке: одобренный план или новый разговор файлов не оставляют.
Такое игра замечает сама, пока ты играешь, и отдаёт тому же скрипту. В третьем
акте скрипт смотрит ещё и на компьютер: лежит ли твой скилл, записан ли хук. В
четвёртом — открывает твой сайт по адресу на компьютере. В пятом — спрашивает
GitHub, видно ли твоё хранилище чужим.

## Что есть сегодня

Играются все пять актов. Каждый рассчитан на один вечер.

**Акт 1 «Знакомство».** Ты делаешь первую версию своей затеи:

1. **Папка.** Ты называешь папку своего проекта.
2. **Идея на вечер.** Выбираешь одно дело на этот вечер, остальное откладываешь.
3. **Первый запрос.** Просишь Claude сделать первую версию и смотришь на неё.
4. **Сохранение.** Просишь Claude сохранить сделанное.
5. **Стоп и отмена.** Останавливаешь Claude на ходу и возвращаешь всё назад.

За акт даётся ранг Искатель.

**Акт 2 «Память и силы».** Ты делаешь следующее дело из своего списка:

1. **План.** Просишь у Claude план и одобряешь его до первой правки.
2. **Покажи.** Показываешь Claude файл проекта и снимок экрана.
3. **Память проекта.** Диктуешь четыре вещи о проекте — Claude пишет их в файл.
4. **Чистый лист.** Записываешь передачу и начинаешь разговор заново с того же места.
5. **Силы.** Смотришь, какая модель тебе отвечает и сколько занято в лимите.

За акт даётся ранг Падаван.

**Акт 3 «Умения».** Claude работает и без добавок, но его можно учить. Ты
учишь его на своём проекте:

1. **Скилл.** Узнаёшь, что такое скилл, и смотришь, какие скиллы у тебя уже есть.
2. **Где брать.** Узнаёшь, где искать готовые скиллы и как ставить их безопасно. Сегодня ничего не ставишь.
3. **Свой скилл.** Диктуешь одно своё правило работы — Claude делает из него скилл.
4. **Хук.** Просишь хук на слово «чистка» и пробуешь это слово.
5. **Мод.** Находишь на экране Claude Code строку о моде игры.

За акт даётся ранг Рыцарь.

**Акт 4 «Свой продукт».** Из своей идеи ты делаешь сайт или Telegram-бота. К
концу вечера он работает на твоём компьютере:

1. **Что строим.** Говоришь, что строишь и для кого, — Claude задаёт вопросы и записывает.
2. **План.** Просишь у Claude план продукта по шагам и одобряешь его.
3. **Сборка.** Смотришь каждый шаг и говоришь «дальше» — Claude сохраняет шаг.
4. **Работает.** Claude запускает продукт: ты открываешь сайт в браузере или пишешь боту.
5. **Приёмка.** Проходишь продукт как пользователь и говоришь «да» или что не так.

За акт даётся ранг Страж.

**Акт 5 «Три места кода».** Код живёт в трёх местах: на компьютере, на GitHub
и на сервере, и везде одна версия. Сегодня — два места из трёх:

1. **GitHub.** Заводишь аккаунт, и Claude подключает к нему твой компьютер.
2. **Приватный репозиторий.** Создаёшь на GitHub закрытое хранилище — Claude отправляет туда код.
3. **Одна версия.** Просишь поправить мелочь и говоришь «сделай коммит и отправь на GitHub».
4. **Чужой сервис.** Даёшь Claude ссылку на документацию сервиса — он подключает его к продукту.
5. **Третье место.** Слушаешь про сервер и домен и пересказываешь своими словами.

За акт даётся ранг Мастер, и на нём игра кончается. Финал зовёт в три места:
на консультацию с автором игры — выложить продукт в интернет, на обучение и в
клуб.

На входе в каждый акт выдаётся приём — готовый способ работы. В первом акте
он помогает найти идею. Во втором это «Передача»: Claude записывает в файл, на
чём вы остановились, и следующий разговор начинается с этого файла. В третьем
— «Разбор поломки»: Claude ищет причину по шагам, а не чинит наугад. В
четвёртом — «Цель»: Claude доводит дело до работы, но не дольше названного
числа попыток. В пятом — «Проверка ключей»: Claude смотрит, не утекают ли из
проекта ключи от чужих сервисов.

## Что ты увидишь на экране

Игра показывает себя в окне Claude Code в четырёх местах:

- **Над полем ввода** стоит строка «Что дальше» с текущим квестом.
- **В поле ввода** до начала акта серым стоит слово «начинаем». Нажми Tab —
  слово впишется.
- **В правом верхнем углу** всплывает сообщение «Квест закрыт».
- **Строки вида `jedicoder - check (MCP)`** значат: игра проверяет квест.

На старой версии Claude Code этого нет: игра идёт как раньше.

## Что нужно

Claude Code нужна платная подписка Claude, Pro или выше.

Во втором акте понадобится снимок экрана. В приложении Голокрон его вставляют
клавишами Ctrl+V. В терминале без приложения файл снимка перетаскивают в окно.

В третьем акте из интернета ничего не ставится: где брать готовые скиллы,
Claude объясняет словами. Ставить их будешь потом сам.

В четвёртом акте продукт строится тем, что уже стоит на компьютере: сайт
открывает встроенный сервер Python, бот обходится без библиотек. Для бота
нужен Telegram: ключ бота выдаёт @BotFather. Сайту ничего не нужно.

В пятом акте нужен аккаунт на GitHub. Регистрация бесплатная, ставить ничего не
надо: Claude подключает компьютер ключом, который делает сам. Наружу уходит
только твой проект, и только в закрытое хранилище. Сервер и домен в игре не
покупаются.

## Как начать через приложение

Приложение Голокрон ставит Claude Code и игру само. Оно есть для Windows,
macOS и Linux. Шагов пять, они описаны в [`docs/act0-install.md`](docs/act0-install.md):
скачать, открыть и ввести ключ, поставить остальное кнопками, войти в Claude,
набрать первую команду.

Ключ бесплатный: его выдают за подписку на канал
[t.me/vibecodejedi](https://t.me/vibecodejedi). Приложение спрашивает ключ при
запуске.

С ключом бот игры видит твой путь: пройденные задания, ранг и очки. Приложение
сообщает ему, какие шаги установки пройдены. Команды и файлы проекта ему не
уходят.

## Как начать в терминале

Этот путь для того, у кого Claude Code уже стоит. Игре нужны `python3` (3.8
или новее), `bash` и `git`. На Windows она работает в Linux внутри Windows (WSL).

Поставь игру. Обе строки набираются в терминале, не внутри Claude Code:

```
claude plugin marketplace add IulaiJedi/jedicoder-game
claude plugin install jedicoder@jedicoder
```

Заведи для проекта новую пустую папку. Открой в ней терминал и запусти Claude
Code:

```
claude --dangerously-skip-permissions
```

Первой командой набери:

```
/jedicoder:start
```

В терминале без приложения игра идёт без ключа и без бота.

Как играть дальше — в [`docs/how-to-play.md`](docs/how-to-play.md).

## Режим без вопросов

Игра ведёт в режиме, где Claude не спрашивает разрешения. В приложении его
включает кнопка «Запустить Claude Code». В терминале — команда запуска выше:
слово dangerously в ней значит «на свой риск».

Честно о том, что это значит. Claude правит файлы и запускает команды, не
спрашивая тебя. Он может ошибиться: испортить страницу или стереть нужный файл.
Поэтому у проекта своя папка, и в ней нет ничего, кроме проекта.

## Если ты играл в прежнюю версию

Игра перестроена, и при обновлении она начинается заново. Пройденное раньше в
новую игру не переходит.

Прежнее сохранение не стирается. Оно уходит в архив рядом:
`~/.jedicoder/state.json.arhiv-<дата>`. Первый экран один раз говорит, где оно
лежит.
