# Jedicoder

Игра, которая учит вайбкодингу. Ставится плагином в Claude Code и играется
**в твоём терминале, на твоём настоящем проекте** — не на учебном. Пять актов
ведут от «непонятно, что строить» до продукта, который работает и доступен
людям.

Главное правило, из которого растёт всё остальное: **исход квеста решает
exit-код bash-скрипта, а не мнение модели.** Игра не может засчитать по
доброте и не может отобрать засчитанное. Скрипт смотрит на твои файлы, твой
git и твой сервер — и отвечает «да» или «нет».

## Сначала — приложение

Игра идёт в приложении Голокрон: оно ставит Claude Code и саму игру само. Как
его скачать и дойти до первой команды — пять шагов, и лежат они в трёх местах,
выбирай любое:

| Дверь | Куда идти | Кому подойдёт |
|---|---|---|
| Telegram-бот | [`@Jedicoderstore_bot`](https://t.me/Jedicoderstore_bot?start=game) | ведёт по пяти шагам кнопками; в конце даёт код для игры |
| Страница на сайте | [jedicoder.store/game/install](https://jedicoder.store/game/install) | то же самое сплошным текстом, без Telegram |
| Файл в этом репозитории | [`docs/act0-install.md`](docs/act0-install.md) | если ты уже здесь и никуда уходить не хочешь |

Инструкция написана **один раз** — в `plugin/content/ru/onboarding/`.
Все три двери читают этот текст: файл выше сгенерирован из него, страница и
бот получают его тем же генератором. Поэтому здесь её и нет: четвёртая копия
разошлась бы с остальными молча.

Акт 0 доводит до первой команды `/jedicoder:start` и на этом заканчивается.
Код от бота в конце необязателен: игра проходится целиком и без него.

## Потом — сама игра

Плагин ставится из маркетплейса Claude Code:

```
claude plugin marketplace add IulaiJedi/jedicoder-game
claude plugin install jedicoder@jedicoder
```

Обе строки выполняются в терминале, не внутри Claude Code.

Единственная команда, которую надо помнить:

```
/jedicoder:start
```

Набирать её **первой командой в свежей сессии**: скиллы и поведенческий
контракт грузятся при старте сессии, и разговор, начатый раньше, пойдёт по
памяти модели, а не по правилам игры.

Дальше — [`docs/how-to-play.md`](docs/how-to-play.md): что такое треки, как
устроен квест, что делать при «не смог проверить».

## Что внутри

```
plugin/content/ru/   контент-ядро: поведенческий контракт, словарь, Кодекс,
                     рецепты, текст Акта 0
plugin/lib/          движок: состояние, ранги, реестр квестов, CLI
plugin/quests/       проверки квестов — bash-скрипты, решающие исход
plugin/skills/       скиллы и артефакты, plugin/hooks/ — хуки Тёмной стороны
docs/                инструкции для человека
scripts/             линтер контента и генераторы производных
tests/               тесты движка, контента и всех проверок
```

Зависимостей у плагина нет: `python3`, `bash`, `git` — и всё. Ни одного
`pip install`, потому что плагин ставится на машину новичка, а каждая
зависимость — лишний способ сломаться.

## Разработчику

```bash
python3 -m pytest                    # тесты
python3 scripts/lint_content.py      # линтер контента
```

Зависимостей нет и у тестов: `pytest` — единственное, что нужно доставить.

Два правила, которые ломаются чаще прочего. Первое: производные контента
(текст Акта 0 для бота, для сайта и markdown выше) руками не правятся
никогда — правится источник в `plugin/content/ru/`, а файл перевыпускается
генератором из `scripts/`; расхождение ловится тестом. Второе: проверки
квестов пишутся на POSIX-подмножестве `awk` и без `grep -i` — складывание
регистра кириллицы зависит от локали, а локаль игрока непредсказуема.

## Про правки со стороны

Код со стороны не принимается — pull request будет закрыт, и лучше узнать об
этом до того, как ты потратишь на него вечер. Причина не в гордости: у игры
один автор, и пока это так, её лицензию и судьбу можно менять одним решением.
Первая слитая чужая правка забирает эту свободу навсегда, а вернуть её потом
нельзя — нужно согласие каждого, кто когда-либо что-то прислал.

А вот **баги нужны, и очень**. Игра идёт на твоей машине, с твоей локалью,
твоим `bash` и твоим `git` — то есть в условиях, которых у автора нет и не
будет. Отдельно не проверен macOS. Заводи
[issue](https://github.com/IulaiJedi/jedicoder-game/issues) и приложи две
вещи: какая у тебя система и что дословно напечатала команда. Этого хватает
почти всегда.

Форкать, менять под себя и играть в свою версию — можно и нужно, ради этого
исходники и открыты.
